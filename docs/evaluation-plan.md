## 현재 확인
- 규칙·상태 머신은 합성 특징값으로 테스트한다. 이 테스트를 모델 정확도라고 부르지 않는다.
- 실제 pretrained 모델로 검은 프레임 미검출, 공식 portrait 사진의 사람·얼굴·표정계수 검출, WebSocket 실제 추론 및 잘못된 JPEG 오류 처리를 확인한다.
- headless 가상 웹캠으로 브라우저 프레임 전송·분석·정지·영상 트랙 해제·중도 종료 기록·새로고침 유지 확인.
- 실제 사람이 노트북 카메라 앞에서 준비자세·입 벌리기·오므리기를 수행하는 수동 통합 검증은 이 서버 환경에서 수행하지 못했다.
- 실제 참가자의 Precision/Recall/F1/FPR, 완료 시점 오차 및 임계값 유효성은 아직 평가하지 않았다.

## 수집 설계
초기 제안: 동의한 성인 5~10명, 준비자세·입 벌리기·오므리기·볼 부풀리기 각각 정상 10회와 조건 미충족 시도를 수집한다.
밝기·안경·거리·얼굴 각도·상체 기울기를 포함한다. 참가자별로 개발/평가 집합을 분리한다.
영상 수집 기능은 기본 구현에 없다. 영상이 필요하면 별도 동의·접근 통제·삭제 기준을 먼저 마련한다.
평가자 정답과 시스템 판정을 시간 기준으로 비교하고, 수동 완료 기록은 자동 판정 성능 계산에서 제외한다.

평가 CSV 열:
participant_code,split,exercise_id,attempt_id,ground_truth,system_prediction,truth_completion_seconds,predicted_completion_seconds,inference_ms,fps,lighting,glasses,distance_cm

TP/FP/FN/TN으로 Precision/Recall/F1/FPR를 계산한다. 기준을 조정한 참가자를 최종 평가 집합에 다시 사용하지 않는다.
확인 불가 프레임과 모델 오류는 별도로 보고한다. 실패를 제외해 정확도를 부풀리지 않는다.
